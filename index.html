About

Food & Beverage Intelligence
Through Data

With nearly 30 years of experience in the hospitality industry — including senior roles in city hotels, luxury resorts, and international chains — I have built a career grounded in operational leadership, financial strategy, and data-informed decision-making.

As a Food & Beverage Manager since 2010, I've overseen multimillion-euro budgets, designed daily workflow pipelines, led cross-functional teams, and implemented reporting systems that improved performance and accountability across departments.

Recognising the growing importance of analytics, I completed a 7-month specialization in Data Analysis at the University of Athens. I've since built interactive dashboards, worked with ETL pipelines, and applied concepts like relational databases and dimensional modeling — bringing real-world hospitality business context to every solution.

These Power BI projects reflect my ability to translate complex operational data into actionable insights, demonstrating how technical proficiency and deep industry knowledge combine to drive measurable results.

Deployment Framework

Hospitality BI Deployment Framework

A production-grade, end-to-end methodology built for real hotel environments — from raw data to live, scheduled reporting.

01

Reusable Template

Every project is built on a reusable .PBIT template — enabling rapid deployment across properties without rebuilding from scratch.

02

SQL Architecture

A robust SQL-based architecture underpins all data pipelines, ensuring scalability, security and consistent query performance.

03

Dynamic Date Dimension

Dynamic Dim_Date generated via Power Query — always current, requiring zero manual updates as the calendar rolls forward.

04

Dimensional Model

A correct dimensional model (star schema) ensuring relationships are clean, DAX measures are reliable and reports are fast.

05

Refresh-Proof Setup

Reports are built to be refresh-proof — parameterised connections and error-handling Power Query steps that survive data changes.

06

Gateway & Scheduled Refresh

On-premises Gateway configuration with scheduled refresh — dashboards update automatically, no manual intervention required.

07

Publish to Service

Reports are published to Power BI Service within a managed Workspace — accessible to the right stakeholders, anywhere, any device.

08

SQL Reconciliation

Reconciliation against SQL source data at every stage — guaranteeing that what the dashboard shows matches what the database holds.

09

Production Simulation

Full production simulation before go-live — stress-testing refresh cycles, user access, and report performance under real conditions.
